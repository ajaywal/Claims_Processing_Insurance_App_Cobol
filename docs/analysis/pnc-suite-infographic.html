PnC Core Suite: billing and claims on the mainframe

Two enterprise-scale applications built beside IBM GenApp so a policy issued in GenApp flows into billing, and a claim paid in ClaimsCore becomes a billing disbursement. Every screen below is drawn from the BMS source, field by field.

01 · Estate

How the three systems talk

ClaimsCore reads GenApp's Db2 tables directly to verify a policy at FNOL. Everything else moves through two event queues, drained in the nightly streams with retry and parking.

Batch Intelligence Studio

        
The studio needs scheduler definitions plus run history and SMF 30. The suite has JCL streams but no Control-M or CA-7 export and no run history.

        
  • Available now: 29 JCL members, 2 nightly streams, step order and COND gating
  • Missing: scheduler export, 30+ nights of run history, SMF 30

      
Not run · no data
SMF Engine

        
SMF records (30, 70/72, 100/101, 110) are written by z/OS, Db2 and CICS while work runs. Nothing has run, so none exist.

        
  • Needs: compile, bind and CICS install on a z/OS LPAR, then a few nights of the streams
