Method & export

  

    

      
How the lineage was built

      
Screen fields were parsed from ssmap.bms (position and length), COMMAREA fields from lgcmarea.cpy, columns from the DDL in cntl/db2cre.jcl, and program references by scanning every .cbl member for each COMMAREA name (comment lines excluded). Screen-to-COMMAREA moves come from the LGTEST* drivers; COMMAREA-to-column binds from the EXEC SQL host variables in the LG*DB01 programs. Guidewire targets and transform rules were then assigned field by field.

    

    

      
What “default Guidewire instance” assumes

      
PolicyCenter base product model (Personal Auto, Homeowners HOE, Commercial Property), ClaimCenter base claim and financials model, BillingCenter producers and payment plans, and ContactManager as the contact master. No customer extensions exist yet, so anything without a base field is proposed as an _Ext field or flagged as a gap. Currency is GBP and country GB because GenApp data is UK-based.

    

    

      
Confidence levels

      

        
APIAttribute name confirmed in Guidewire Cloud API documentation (personal vehicle make, model, modelYear, vin, costNew, licenseState).

        
DMBase data model entity.field. Validate against the target instance’s Data Dictionary before build, since names vary by release and line-of-business content.

        
EXTProposed extension or APD product element; does not exist in a default instance.

        
--No Guidewire target.
